# 🎙️ Voice to Action

Voice to Action is a web application that converts spoken thoughts into actionable tasks.

## 🚀 Features

- 🎙️ Voice recording using the browser
- 📝 Converts voice input into a transcript
- ✨ Creates actionable tasks from voice notes
- 📌 Assigns task priority
- ⏳ Tracks task status
- 💾 Saves actions in MongoDB
- 📋 Displays previously saved actions

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas

## ⚙️ How It Works

1. Click **Start Recording**.
2. Speak your task or thought.
3. The speech is converted into text.
4. Click **Create Action**.
5. The action is stored in MongoDB.
6. Saved actions are displayed on the website.
